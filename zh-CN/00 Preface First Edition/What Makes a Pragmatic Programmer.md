## 是什么造就了一个务实的程序员？

<a id="d24e430"></a>
每个开发人员都是独一无二的，都有各自的优点和缺点、偏好和厌恶。随着时间的推移，每个人都会打造自己的个人环境。这种环境将像程序员的爱好、服装或发型一样有力地反映他或她的个性。但是，如果您是一名务实的程序员，您将具有以下许多特征：

<a id="d24e440"></a>
<a id="d24e449"></a>
<a id="d24e474"></a>
<a id="d24e488"></a>
<a id="d24e503"></a>
早期采用者/快速适应者：您对技术和技巧有直觉，并且喜欢尝试。当获得新知识时，您可以快速掌握它并将其与您的其他知识相结合。你的自信源于经验。

好奇：你倾向于提出问题。太棒了——你是怎么做到的？您使用该库有问题吗？我听说过的量子计算是什么？符号链接是如何实现的？你是一个喜欢收集小事实的人，每一个小事实都可能影响几年后的一些决定。

批判性思考者：在没有首先了解事实的情况下，你很少会认为事情是既定的。当同事说“因为事情就是这样做的”，或者供应商承诺解决你所有的问题时，你就会闻到挑战的味道。

现实：您尝试了解您面临的每个问题的根本性质。这种现实主义让你很好地感受到事情有多困难，以及事情需要多长时间。深刻理解一个过程应该是困难的或需要一段时间才能完成，这会给你坚持下去的耐力。

万事通：你努力熟悉各种技术和环境，并努力跟上新的发展。尽管您当前的工作可能要求您成为专家，但您始终能够进入新领域和新挑战。

<a id="d24e507"></a>
我们把最基本的特征留到最后。所有务实的程序员都分享它们。它们足够基本，可以作为提示说明：

**提示 1：关心你的手艺**

<a id="d24e515"></a>
我们认为，除非您关心做好软件，否则开发软件就没有意义。

**提示2：思考！关于你的工作**

<a id="d24e537"></a>
为了成为一名务实的程序员，我们要求您在做事时思考自己在做什么。这不是对当前实践的一次性审核，而是对您每天所做的每一个决定以及每个项目的持续批判性评估。切勿自动驾驶。不断思考，实时批评你的工作。古老的 IBM 公司座右铭“思考！”是务实程序员的口头禅。

<a id="d24e551"></a>
如果这对你来说听起来很辛苦，那么你就表现出了现实的特征。这将占用你一些宝贵的时间——这些时间可能已经承受着巨大的压力。回报是更积极地投入到你喜欢的工作中，对越来越多的科目有一种掌握的感觉，以及不断进步的快乐感。从长远来看，随着您和您的团队变得更加高效、编写更易于维护的代码以及花在会议上的时间更少，您的时间投入将会得到回报。
