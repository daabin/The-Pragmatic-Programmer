## 主题 46. 破解不可能的谜题

> 弗里吉亚国王戈迪乌斯曾经打过一个无人能解开的结。据说，谁解开了快刀斩乱麻之谜，谁就能统治整个亚洲。亚历山大大帝出现了，他用剑将结砍成碎片。只是对要求的解释有点不同，仅此而已……他最终确实统治了亚洲大部分地区。

<a id="d24e24962"></a>
时不时地，当一个非常棘手的难题出现时，您会发现自己陷入了一个项目的中间：某些工程您无法掌握，或者某些代码可能比您想象的更难编写。也许看起来不可能。但这真的像看起来那么难吗？

<a id="d24e24978"></a>
考虑一下现实世界中的谜题——那些狡猾的小木头、锻铁或塑料碎片，它们似乎作为圣诞礼物或车库拍卖品出现。您所要做的就是取下环，或者将 T 形件放入盒子中，或者其他什么。

<a id="d24e24980"></a>
因此，您拉动环，或者尝试将 T 放入盒子中，很快就会发现明显的解决方案不起作用。谜题不能这样解决。但尽管这是显而易见的，但这并不能阻止人们一遍又一遍地尝试同样的事情，并认为一定有办法。

<a id="d24e24982"></a>
当然，没有。解决方案在别处。解决难题的秘诀是识别真实的（不是想象的）约束，并从中找到解决方案。有些限制是绝对的；其他的只是先入为主的观念。绝对的约束必须得到尊重，无论它们看起来多么令人厌恶或愚蠢。

<a id="d24e25011"></a>
另一方面，正如亚历山大所证明的那样，一些表面上的约束可能根本不是真正的约束。许多软件问题也可能同样难以捉摸。

<a id="pg-fppose"></a>
### 自由度

<a id="d24e25016"></a>
流行的流行语“跳出框框思考”鼓励我们认识到可能不适用的限制并忽略它们。但这句话并不完全准确。如果“盒子”是约束和条件的边界，那么关键就是找到这个盒子，它可能比你想象的要大得多。

<a id="d24e25021"></a>
解决谜题的关键是要认识到你所受到的限制，并认识到你所拥有的自由度，因为在这些自由度中你会找到你的解决方案。这就是为什么有些谜题如此有效；您可能会轻易地拒绝潜在的解决方案。

<a id="d24e25026"></a>
例如，您能否将以下谜题中的所有点连接起来，并仅用三条直线返回到起点，而无需将笔从纸上抬起或重新跟踪您的步骤（[*数学谜题和游戏* [Hol92]](<../A2 Exercise Answers/README.md#d6040e510>)）？

<a id="d24e25032"></a>
![Four dots are shown.](https://panzhongxian.cn/images/the-pragmatic-programmer/four_dots_question.png)

<a id="d24e25033"></a>
你必须挑战任何先入为主的观念，并评估它们是否是真正的、严格的限制。

<a id="d24e25035"></a>
问题不在于你是在框内思考还是在框外思考。问题在于找到盒子——找出真正的限制。

**提示 81：不要跳出框框思考——找到框框**

<a id="d24e25053"></a>
当遇到棘手的问题时，列举你面前的所有可能的途径。不要忽视任何东西，无论它听起来多么无用或愚蠢。现在浏览该列表并解释为什么不能采用某条路径。你确定吗？你能证明吗？

<a id="d24e25061"></a>
考虑特洛伊木马——解决棘手问题的新颖方法。如何让部队进入有城墙的城市而不被发现？你可以打赌，“从前门”最初被认为是自杀。

<a id="d24e25064"></a>
对您的限制进行分类并确定优先级。当木工开始一个项目时，他们首先切割最长的木块，然后从剩余的木材中切割出较小的木块。以同样的方式，我们希望首先确定最严格的约束，然后将其余的约束纳入其中。

<a id="d24e25066"></a>
顺便说一下，[在书的最后](<../A2 Exercise Answers/README.md#fourpost>) 显示了四柱谜题的解决方案。

### 走出自己的路！

<a id="d24e25074"></a>
有时你会发现自己正在解决的问题似乎比你想象的要困难得多。也许感觉你走错了路——一定有比这更简单的方法！也许你现在已经按计划迟到了，或者甚至对让系统正常工作感到绝望，因为这个特定的问题是“不可能的”。

<a id="d24e25080"></a>
这是暂时做其他事情的理想时机。做一些不同的事情。去遛狗吧睡在上面吧

<a id="d24e25082"></a>
你的有意识的大脑意识到了这个问题，但你的有意识的大脑真的很愚蠢（无意冒犯）。所以是时候给你真正的大脑，那个潜伏在你意识之下的令人惊奇的联想神经网络，一些空间了。你会惊讶地发现，当你故意分散自己的注意力时，答案经常会突然出现在你的脑海中。

<a id="d24e25084"></a>
<a id="FNPTR-72"></a>
如果这对你来说太神秘了，其实不然。今日心理学[[72]](<48 The Essence of Agility - essence_of_agility.md#FOOTNOTE-72>) 报道：

<a id="d24e25094"></a>
> 简单地说，分心的人在复杂的事情上表现得更好
> 解决问题的任务比有意识地付出努力的人要好。

<a id="d24e25096"></a>
如果你暂时还不愿意放弃这个问题，那么下一个最好的办法可能就是找人解释一下。通常，简单地谈论它会分散你的注意力，从而让你得到启发。

<a id="d24e25102"></a>
让他们问你一些问题，例如：

<a id="d24e25110"></a>
<a id="d24e25113"></a>
<a id="d24e25116"></a>
<a id="d24e25119"></a>
- 你为什么要解决这个问题？
- 解决了有什么好处呢？
- 您遇到的问题与边缘情况有关吗？你能消灭它们吗？
- 有没有一个更简单、相关的问题可以解决？

<a id="d24e25121"></a>

### 财富眷顾有准备的头脑

<a id="d24e25126"></a>
据报道，路易斯·巴斯德曾说过：

<a id="d24e25129"></a>
> 哈萨德观察的冠军不喜欢精神
> 准备工作。
> （就观察而言，命运眷顾有准备的头脑。）

<a id="d24e25135"></a>
对于解决问题也是如此。为了拥有那些尤里卡！时刻，你的无意识大脑需要有充足的原材料；以前的经验可以有助于回答。

<a id="d24e25140"></a>
喂养你的大脑的一个好方法就是在你日常工作时给它反馈什么有效、什么无效。我们描述了一种使用工程日记本（主题 22，[*工程日记*](<../03 Basic Tools/22 Engineering Daybooks - daybook.md#daybook>)）来实现这一点的好方法。
