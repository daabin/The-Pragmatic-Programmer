## 主题 17. Shell 把戏

<a id="d24e7163"></a>
每个木工都需要一个良好、坚固、可靠的工作台，在工件成型时将其固定在合适的高度。工作台成为木工车间的中心，随着一件作品的成型，制作者一次又一次地回到它。

<a id="d24e7169"></a>
对于操作文本文件的程序员来说，该工作台就是命令 shell。从 shell 提示符中，您可以调用完整的工具库，使用管道以原始开发人员从未梦想过的方式将它们组合起来。您可以从 shell 启动应用程序、调试器、浏览器、编辑器和实用程序。您可以搜索文件、查询系统状态以及过滤输出。通过对 shell 进行编程，您可以为经常执行的活动构建复杂的宏命令。

<a id="d24e7175"></a>
对于在 GUI 界面和集成开发环境 (IDE) 中长大的程序员来说，这似乎是一个极端的立场。毕竟，您不能通过指向和单击来同样出色地完成所有事情吗？

<a id="d24e7201"></a>
简单的答案是“不”。GUI 界面很棒，对于一些简单的操作来说它们可以更快、更方便。移动文件、读写电子邮件以及构建和部署项目都是您可能想要在图形环境中完成的事情。但是如果您使用 GUI 完成所有工作，您将错过环境的全部功能。您将无法自动执行常见任务，也无法使用可用工具的全部功能。并且您将无法组合工具来创建自定义宏GUI 的优点是所见即所得，缺点是所见即所得。

<a id="d24e7215"></a>
GUI 环境通常仅限于其设计者想要的功能。如果您需要超越设计师提供的模型，那么您通常会不走运，而且通常情况下，您确实需要超越模型。务实的程序员不只是剪切代码、开发对象模型、编写文档或自动化构建过程——我们会做所有这些事情。任何一种工具的范围通常仅限于该工具预期执行的任务。例如，假设您需要将代码预处理器（以实现按合同设计或多处理编译指示等）集成到您的 IDE 中。除非 IDE 的设计者明确提供了此功能的挂钩，否则您无法做到这一点。

**提示 26：使用命令 Shell 的强大功能**

<a id="d24e7229"></a>
熟悉 shell，您会发现您的工作效率大幅提升。需要创建由 Java 代码显式导入的所有唯一包名称的列表？以下代码将其存储在名为“list”的文件中：

[sh/packages.sh](http://media.pragprog.com/titles/tpp20/code/sh/packages.sh)

```
grep '^import ' *.java |
  sed -e's/.*import  *//' -e's/;.*$//' |
  sort -u >list
```

<a id="d24e7258"></a>
如果您没有花太多时间探索您使用的系统上命令 shell 的功能，这可能会让人望而生畏。然而，投入一些精力来熟悉你的 shell，一切很快就会开始变得井然有序。尝试一下您的命令 shell，您会惊讶地发现它使您的工作效率大大提高。

### 你自己的外壳

<a id="d24e7264"></a>
就像木工定制他们的工作空间一样，开发人员也应该定制他们的外壳。这通常还涉及更改您使用的终端程序的配置。

<a id="d24e7275"></a>
常见的变化包括：

<a id="d24e7279"></a>
<a id="d24e7294"></a>
<a id="d24e7303"></a>
<a id="d24e7320"></a>
<a id="d24e7332"></a>
- 设置颜色主题。您可以花费很多很多时间来尝试针对您的特定 shell 在线提供的每个主题。
- 配置提示。告诉您 shell 已准备好输入命令的提示可以配置为显示您可能想要的任何信息（以及一堆您永远不需要的信息）。个人喜好就是一切：我们倾向于喜欢简单的提示，带有缩短的当前目录名称和版本控制状态以及时间。
- 别名和 shell 函数。将您经常使用的命令转变为简单的别名，从而简化您的工作流程。也许你定期更新你的 Linux 机器，但永远记不起是更新再升级，还是升级再更新。创建别名：

  ```
  alias apt-up='sudo apt-get update  sudo apt-get upgrade'
  ```

也许您经常不小心使用 rm 命令删除文件一次。写一个别名，这样以后总会提示：

  ```
  alias rm ='rm -iv'
  ```
- 命令完成。大多数 shell 都会完成命令和文件的名称：输入前几个字符，按 Tab 键，它就会填写它可以填写的内容。但是您可以更进一步，将 shell 配置为识别您正在输入的命令并提供特定于上下文的完成。有些甚至根据当前目录自定义完成。

<a id="d24e7355"></a>
你会花很多时间生活在这些外壳中。像寄居蟹一样，把它当作自己的家。
