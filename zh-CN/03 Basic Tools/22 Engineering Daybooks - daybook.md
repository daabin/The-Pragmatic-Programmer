## 主题 22. 工程日志

<a id="d24e8882"></a>
戴夫曾经在一家小型计算机制造商工作，这意味着与电子工程师、有时是机械工程师一起工作。

<a id="d24e8896"></a>
他们中的许多人带着纸质笔记本走来走去，通常在书脊上塞着一支笔。当我们谈话时，他们时不时地打开笔记本并写下一些东西。

<a id="d24e8898"></a>
最终戴夫问了一个显而易见的问题。事实证明，他们受过训练，要保留一本工程日记本，一种记录他们所做的事情、学到的东西、想法草图、仪表读数的日记：基本上是与他们的工作有关的任何事情。当笔记本写满时，他们会在书脊上写下日期范围，然后将其贴在架子上之前的日记本旁边。可能存在一场温和的竞争，争夺谁的书占据了最多的书架空间。

<a id="d24e8903"></a>
<a id="FNPTR-29"></a>
我们使用日记本在会议中做笔记，记下我们正在做的事情，在调试时记下变量值，在我们放置东西的地方留下提醒，记录疯狂的想法，有时只是涂鸦。[[29]](#FOOTNOTE-29)

<a id="d24e8912"></a>
日记本具有三个主要优点：

<a id="d24e8916"></a>
<a id="d24e8919"></a>
<a id="d24e8922"></a>
- 它比记忆更可靠。人们可能会问“你上周就供电问题打电话给那家公司叫什么名字？”你可以向后翻一页左右，告诉他们姓名和电话号码。
- 它为您提供了一个存储与手头任务不直接相关的想法的地方。这样你就可以继续专注于你正在做的事情，知道这个伟大的想法不会被忘记。
- 它充当一种橡皮鸭（描述为<a href="20%20Debugging%20-%20debug#rubber-ducking">这里</a>）。当你停下来写下一些东西时，你的大脑可能会切换齿轮，几乎就像在与某人交谈一样——这是一个反思的好机会。您可能开始做笔记，然后突然意识到您刚刚所做的事情，即笔记的主题，完全是错误的。

<a id="d24e8930"></a>
还有一个额外的好处。你可以时不时地回顾一下你很多年前所做的事情，想想那些人、那些项目、以及那些糟糕的衣服和发型。

<a id="d24e8932"></a>
因此，尝试保留一本工程日记本。使用纸张，而不是文件或维基：与打字相比，书写行为有一些特殊之处。给它一个月的时间，看看你是否能得到任何好处。

<a id="d24e8934"></a>
如果不出意外的话，当你变得富有和出名时，这会让你的回忆录变得更容易。
