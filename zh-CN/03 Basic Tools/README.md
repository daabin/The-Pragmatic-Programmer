# 第 3 章 - 基础工具

<a id="d24e6753"></a>
每个创客都是从一套基本的优质工具开始他们的旅程的。木工可能需要尺子、量规、几把锯子、一些好的刨子、精致的凿子、钻头和支架、木槌和夹子。这些工具将经过精心挑选，经久耐用，能够执行特定的工作，与其他工具几乎没有重叠，而且，也许最重要的是，在崭露头角的木工手中感觉很舒服。

<a id="d24e6759"></a>
然后开始一个学习和适应的过程。每个工具都有自己的个性和怪癖，并且需要自己的特殊处理。每一个都必须以独特的方式打磨，或者就这样保持。随着时间的推移，每个工具都会根据使用情况而磨损，直到手柄看起来像木工手上的模具，并且切割表面与工具握持的角度完美对齐。此时，工具成为从制造者的大脑到成品的管道——它们已经成为他们双手的延伸。随着时间的推移，木工将添加新的工具，例如饼干切割机、激光引导斜切锯、燕尾夹具——所有这些都是奇妙的技术。但你可以打赌，他们会对手中的这些原始工具感到最满意，感受飞机滑过树林时发出的声音。

<a id="d24e6761"></a>
工具可以增强您的才能。您的工具越好，您越了解如何使用它们，您的工作效率就越高。从一组基本的普遍适用的工具开始。当您获得经验并遇到特殊要求时，您将添加到这个基本集合中。像制造商一样，期望定期添加到您的工具箱中。始终寻找更好的做事方法。如果您遇到感觉当前工具无法解决问题的情况，请记下以寻找不同或更强大的工具来提供帮助。让需求驱动您的收购。

<a id="d24e6763"></a>
许多新程序员都会犯这样的错误：采用单一的强大工具，例如特定的集成开发环境（IDE），并且永远不会离开其舒适的界面。这确实是一个错误。您需要超越 IDE 所施加的限制。做到这一点的唯一方法是保持基本工具集锋利并随时可用。

<a id="d24e6769"></a>
在本章中，我们将讨论投资自己的基本工具箱。与任何有关工具的良好讨论一样，我们将从查看您的原材料（即您将要塑造的东西）开始（在主题 16，<a href="16%20The%20Power%20of%20Plain%20Text%20-%20plain_text#plain_text">纯文本的力量</a> 中）。从那里我们将移动到工作台，或者在我们的例子中移动到计算机。如何使用计算机来充分利用所使用的工具？我们将在主题 17，<a href="17%20Shell%20Games%20-%20know_your_shell#know_your_shell">贝壳游戏</a> 中讨论这个问题。现在我们有了可以使用的材料和工作台，我们将转向您可能会使用得最多的工具，即您的编辑器。在主题 18 <a href="18%20Power%20Editing%20-%20get_good_at_editing#get_good_at_editing">强力编辑</a> 中，我们将建议提高效率的方法。

<a id="d24e6795"></a>
为了确保我们永远不会丢失任何宝贵的工作，我们应该始终使用主题 19，<a href="19%20Version%20Control%20-%20version_control#version_control">版本控制</a> 系统 - 即使对于个人事物，例如食谱或笔记。而且，由于 Murphy 毕竟是一位乐观主义者，因此在主题 20 <a href="20%20Debugging%20-%20debug#debug">调试</a> 上变得非常熟练之前，您不可能成为一名出色的程序员。

<a id="d24e6810"></a>
你需要一些胶水将大部分魔法粘合在一起。我们在主题 21，<a href="21%20Text%20Manipulation%20-%20text_manip#text_manip">文本操作</a> 中讨论一些可能性。

<a id="d24e6828"></a>
最后，最苍白的墨水，依然胜过最好的记忆。跟踪您的想法和历史，如我们在主题 22 <a href="22%20Engineering%20Daybooks%20-%20daybook#daybook">工程日记</a> 中所述。

<a id="d24e6842"></a>
花时间学习使用这些工具，在某些时候，您会惊讶地发现您的手指在键盘上移动，无需有意识地思考即可操作文本。这些工具将成为你双手的延伸。
