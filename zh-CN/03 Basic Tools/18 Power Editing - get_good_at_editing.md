## 主题 18. 强力编辑

<a id="d24e7413"></a>
我们之前讨论过工具是你手的延伸。嗯，这对于编辑器来说比任何其他软件工具都更适用。您需要能够尽可能轻松地操作文本，因为文本是编程的基本原材料。

<a id="d24e7424"></a>
在本书的第一版中，我们建议对所有内容使用单一编辑器：代码、文档、备忘录、系统管理等等。我们已经软化了这一立场。我们很高兴您可以使用任意数量的编辑器。我们只是希望您能够流利地掌握每一项内容。

**提示 27：实现编辑器的流畅性**

<a id="d24e7432"></a>
为什么这很重要？我们是说您会节省很多时间吗？实际上是的：在一年的时间里，如果您将编辑效率提高 4% 并且每周编辑 20 小时，您实际上可能会多获得一周的时间。

<a id="d24e7438"></a>
但这并不是真正的好处。不，主要的收获是，通过变得流利，你不再需要考虑编辑的机制。思考某件事和让它出现在编辑器缓冲区中之间的距离大大缩短了。你的思想将会流动，你的编程也会受益。 （如果您曾经教过某人开车，那么您就会明白必须考虑自己采取的每一个行动的人与本能地控制汽车的更有经验的驾驶员之间的区别。）

### 迈向流利

<a id="d24e7506"></a>
我们怀疑知道任何特定强大编辑器中所有命令的人不止少数。我们也不指望你这么做。相反，我们建议采取更务实的方法：学习让您的生活更轻松的命令。

<a id="d24e7511"></a>
这个方法相当简单。

<a id="d24e7513"></a>
首先，在编辑时审视自己。每当你发现自己在做重复的事情时，养成思考“一定有更好的方法”的习惯。然后找到它。

<a id="d24e7515"></a>
一旦您发现了一项新的、有用的功能，您现在需要将其安装到您的肌肉记忆中，这样您就可以不假思索地使用它。我们知道做到这一点的唯一方法是通过重复。有意识地寻找机会使用你的新超能力，最好每天多次。大约一周后，你会发现你不假思索地使用它。

#### 培养你的编辑器

<a id="d24e7520"></a>
大多数强大的代码编辑器都是围绕基本核心构建的，然后通过扩展进行增强。许多是随编辑器提供的，其他的可以稍后添加。

<a id="d24e7531"></a>
当您遇到正在使用的编辑器的一些明显限制时，请四处搜索可以完成这项工作的扩展。很可能您并不是唯一需要这种功能的人，如果您幸运的话，其他人也会发布他们的解决方案。

<a id="d24e7533"></a>
更进一步。深入研究编辑器的扩展语言。了解如何使用它来自动化您所做的一些重复性工作。通常您只需要一两行代码。

<a id="d24e7535"></a>
有时您可能会更进一步，您会发现自己正在编写一个成熟的扩展。如果是这样，请发布它：如果您需要它，其他人也会这样做。

- 不再自动重复。

每个人都会这样做：你需要删除你输入的最后一个单词，所以你按下退格键并等待自动重复启动。事实上，我们打赌你的大脑已经做了很多这样的事情，以至于你可以非常准确地判断何时释放按键。

因此，关闭自动重复，而是学习按字符、单词、行和块移动、选择和删除的按键序列。
- 这会很痛。

丢失鼠标/触控板。整整一周，只使用键盘进行编辑。您会发现很多如果不通过指向和单击就无法完成的事情，所以现在是学习的时候了。记下您所学的关键序列（我们建议使用老式方法并使用铅笔和纸）。

您的工作效率将会受到几天的影响。但是，当您学会在不将手从起始位置移开的情况下做事时，您会发现您的编辑变得比过去更快、更流畅。
- 寻找集成。在撰写本章时，Dave 想知道是否可以在编辑器缓冲区中预览最终布局（PDF 文件）。下载一次后，布局就位于原始文本旁边，全部在编辑器中。列出您想要带入编辑器的内容，然后查找它们。
- 更雄心勃勃的是，如果您找不到可以实现您想要的功能的插件或扩展，请编写一个。 Andy 喜欢为他最喜欢的编辑器制作定制的、基于本地文件的 Wiki 插件。如果找不到它，就构建它！
