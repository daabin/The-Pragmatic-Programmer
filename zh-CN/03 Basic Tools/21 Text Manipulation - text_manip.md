## 主题 21. 文本处理

<a id="d24e8667"></a>
务实的程序员操作文本的方式与木工塑造木材的方式相同。在前面的部分中，我们讨论了我们使用的一些特定工具——shell、编辑器、调试器。它们类似于木工的凿子、锯子和刨子，都是专门用来完成一两项工作的工具。然而，我们时不时地需要执行一些基本工具集无法轻松处理的转换。我们需要一个通用的文本操作工具。

<a id="d24e8678"></a>
<a id="FNPTR-28"></a>
文本操作语言之于编程就像路由器<a href="22%20Engineering%20Daybooks%20-%20daybook#FOOTNOTE-28">[28]</a>之于木工一样。它们吵闹、混乱，而且有些暴力。如果使用错误，整个作品可能会被毁掉。有些人发誓工具箱里没有他们的位置。但在正确的人手中，路由器和文本操作语言都可以非常强大和多功能。您可以快速将某物修剪成形、制作接头和雕刻。如果使用得当，这些工具具有令人惊讶的技巧和微妙。但它们需要时间来掌握。

<a id="d24e8687"></a>
幸运的是，有许多很棒的文本操作语言。 Unix 开发人员（这里包括 macOS 用户）通常喜欢使用命令 shell 的强大功能，并通过 awk 和 sed 等工具进行增强。喜欢更结构化工具的人可能更喜欢 Python 或 Ruby 等语言。

<a id="d24e8702"></a>
这些语言是重要的支持技术。使用它们，您可以快速破解实用程序和原型想法，而使用传统语言可能需要五到十倍的时间。这个乘数对于我们所做的实验至关重要。花 30 分钟尝试一个疯狂的想法比花 5 个小时要好得多。花一天时间自动化项目的重要组件是可以接受的；花一周可能不会。在他们的书 <a href="../A2%20Exercise%20Answers/#d6040e743">*编程实践* [KP99]</a> 中，Kernighan 和 Pike 用五种不同的语言构建了相同的程序。 Perl 版本是最短的（17 行，而 C 的有 150 行）。使用 Perl，您可以操作文本、与程序交互、通过网络交谈、驱动网页、执行任意精度算术以及编写看起来像史努比咒骂的程序。
