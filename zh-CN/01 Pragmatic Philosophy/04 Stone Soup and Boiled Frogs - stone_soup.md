## 主题 4. 石头汤与温水煮青蛙

<a id="d24e1215"></a>
三个从战场归来的士兵都饿了。当他们看到前面的村庄时，他们的精神振奋起来——他们确信村民们会给他们一顿饭。但当他们到达那里时，却发现门锁着，窗户也关着。经过多年战乱，村民们粮食匮乏，纷纷囤积起来。

<a id="d24e1218"></a>
士兵们并没有被吓倒，他们烧开了一锅水，小心翼翼地把三块石头放进去。惊讶的村民纷纷出来观看。

<a id="d24e1222"></a>
“这是石头汤。”士兵们解释道。 “这就是你放的全部吗？”村民们问道。 “当然——虽然有人说加几根胡萝卜味道更好……”一个村民跑开，很快就从他的宝库里拎了一篮子胡萝卜回来。

<a id="d24e1225"></a>
几分钟后，村民们又问：“是吗？”

<a id="d24e1228"></a>
“好吧，”士兵们说，“几个土豆就可以给它补充能量。”另一位村民跑了出去。

<a id="d24e1231"></a>
在接下来的一个小时里，士兵们列出了更多可以增强汤味的配料：牛肉、韭菜、盐和香草。每次都有不同的村民跑去袭击他们的个人商店。

<a id="d24e1234"></a>
最终他们熬出了一大锅热气腾腾的汤。士兵们搬走了石头，他们和全村人一起坐下来享受几个月来吃的第一顿大餐。

<a id="d24e1237"></a>
石头汤的故事有几个寓意。村民们被士兵欺骗，他们利用村民的好奇心从他们那里获取食物。但更重要的是，士兵们充当了催化剂，将村庄聚集在一起，这样他们就可以共同创造出他们自己无法完成的事情——一个协同的结果。最终每个人都赢了。

<a id="d24e1256"></a>
有时，您可能想效仿士兵。

<a id="d24e1259"></a>
您可能处于这样一种情况：您确切地知道需要做什么以及如何做。整个系统就出现在你的眼前——你知道它是对的。但如果你需要获得许可来解决整个问题，你就会遇到延误和茫然的眼神。人们将组建委员会，预算需要批准，事情会变得复杂。每个人都会守护自己的资源。有时这被称为“启动疲劳”。

<a id="d24e1268"></a>
<a id="FNPTR-7"></a>
是时候把石头拿出来了。弄清楚你可以合理要求什么。好好开发吧。一旦你掌握了它，就向人们展示，让他们惊叹不已。然后说“当然，如果我们添加......那就更好了”假装这并不重要。坐下来等待他们开始要求您添加您最初想要的功能。人们发现更容易加入持续的成功。向他们展示未来的一瞥，您会让他们团结起来。[[7]](<07 Communicate - communicate.md#FOOTNOTE-7>)

**提示 6：成为变革的催化剂**

### 村民那边

<a id="d24e1297"></a>
另一方面，石汤的故事也是关于温柔渐进的欺骗。这是因为注意力太集中了。村民们只想着石头，忘记了世界其他地方。我们每天都为之倾倒。事情就这样悄悄发生在我们身上。

<a id="d24e1299"></a>
我们都见过这些症状。项目会慢慢地、不可避免地完全失控。大多数软件灾难一开始都太小而无法引起注意，而且大多数项目超支都是一天一次发生的。系统逐个功能地偏离其规范，而补丁又被添加到一段代码中，直到没有留下任何原始补丁。往往是小事情的积累破坏了士气和团队。

**提示 7：记住大局**

<a id="d24e1316"></a>
老实说，我们从来没有尝试过这个。但“他们”说，如果你把一只青蛙扔进沸水中，它会直接跳回来。然而，如果你将青蛙放入装有冷水的锅中，然后逐渐加热，青蛙不会注意到温度的缓慢升高，并且会留在原处直到煮熟。

<a id="d24e1318"></a>
请注意，青蛙的问题与主题 3 [*软件熵*](<03 Software Entropy - no_broken_windows.md#no_broken_windows>) 中讨论的破窗问题不同。在破窗理论中，人们失去了对抗熵的意愿，因为他们认为没有人关心。青蛙只是没有注意到这种变化。

<a id="d24e1322"></a>
不要像传说中的青蛙那样。密切关注大局。不断回顾你周围发生的事情，而不仅仅是你个人正在做的事情。

### 挑战

<a id="d24e1339"></a>
<a id="d24e1364"></a>
- 在审阅第一版草稿时，约翰·拉科斯提出了以下问题：士兵们逐渐欺骗了村民，但他们所催化的变化对他们都有好处。然而，通过逐渐欺骗青蛙，你正在伤害它。当你尝试推动变革时，你能确定自己是在做石头汤还是青蛙汤吗？这个决定是主观的还是客观的？
- 快点，不用看，你头顶的天花板上有多少盏灯？房间有几个出口？有多少人？有没有什么断章取义的东西，或者看起来不属于它的东西？这是一种态势感知练习，从男女童子军到海豹突击队，人们都在练习这种技术。养成认真观察和注意周围环境的习惯。然后对您的项目执行相同的操作。
