# 第 1 章 - 务实的哲学

<a id="d24e641"></a>
这本书是关于你的。

<a id="d24e643"></a>
别搞错了，这是你的职业，更重要的是主题1，[*这是你的生活*](<01 It's Your Life - its_your_life.md#its_your_life>)。你拥有它。您来到这里是因为您知道自己可以成为更好的开发人员并帮助其他人变得更好。您可以成为一名务实的程序员。

<a id="d24e665"></a>
务实程序员的特点是什么？我们认为这是一种态度、一种风格、一种处理问题及其解决方案的哲学。他们的思考超越眼前的问题，将其置于更大的背景中并寻求更大的前景。毕竟，没有这个更大的背景，你怎么能务实呢？如何做出明智的妥协和明智的决定？

<a id="d24e686"></a>
务实的程序员成功的另一个关键是他们对自己所做的一切负责，我们将在主题 2 [*猫吃了我的源代码*](<02 The Cat Ate My Source Code - responsibility.md#responsibility>) 中讨论这一点。负责任的务实程序员不会袖手旁观，眼睁睁地看着他们的项目因疏忽而崩溃。在主题 3 [*软件熵*](<03 Software Entropy - no_broken_windows.md#no_broken_windows>) 中，我们将告诉您如何保持项目的原始状态。

<a id="d24e706"></a>
大多数人发现改变很困难，有时是出于充分的理由，有时是因为简单的惯性。在主题 4 [*石汤和水煮田鸡*](<04 Stone Soup and Boiled Frogs - stone_soup.md#stone_soup>) 中，我们研究了一种促进变革的策略，并（为了平衡）呈现了一个两栖动物忽视渐进变革危险的警示故事。

<a id="d24e748"></a>
了解您工作环境的好处之一是可以更轻松地了解您的软件必须有多好。有时近乎完美是唯一的选择，但通常需要权衡。我们在主题 5 [*足够好的软件*](<05 Good-Enough Software - good_enough_sw.md#good_enough_sw>) 中对此进行探讨。

<a id="d24e764"></a>
当然，您需要拥有广泛的知识和经验基础才能实现这一切。学习是一个持续不断的过程。在主题 6 [*您的知识组合*](<06 Your Knowledge Portfolio - knowledge.md#knowledge>) 中，我们讨论了一些保持势头的策略。

<a id="d24e787"></a>
最后，我们没有人在真空中工作。我们都花费大量时间与他人互动。主题 7，[*交流！*](<07 Communicate - communicate.md#communicate>) 列出了我们可以做得更好的方法。

<a id="d24e796"></a>
务实编程源于务实思维的哲学。本章奠定了这一理念的基础。
