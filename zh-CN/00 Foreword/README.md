# 前言

<a id="d24e140"></a>
我记得戴夫和安迪第一次在推特上谈论这本书的新版本时。这是个大新闻。我看到编码社区的反应很兴奋。我的动态充满了期待。二十年后，《程序员修炼之道》在今天和当时一样具有现实意义。

<a id="d24e145"></a>
一本有如此历史的书能引起如此反响，足以说明一切。我有幸阅读了一份未发行的副本来写这篇前言，我明白了为什么它引起了如此大的轰动。虽然这是一本技术书，但这样称呼它却是一种伤害。技术书籍常常令人生畏。它们充满了大词、晦涩的术语、令人费解的例子，无意中让你觉得自己很愚蠢。作者经验越丰富，就越容易忘记学习新概念、成为初学者是什么感觉。

<a id="d24e147"></a>
尽管戴夫和安迪拥有数十年的编程经验，但他们还是像刚刚学到这些课程的人一样兴奋地克服了写作的艰巨挑战。他们不会居高临下地对你说话。他们不认为你是专家。他们甚至不假设你已经读过第一版。他们认为你本来就是一个只想变得更好的程序员。他们用本书的篇幅帮助您实现这一目标，一次一个可行的步骤。

<a id="d24e149"></a>
公平地说，他们以前已经这样做过。最初的版本充满了具体的示例、新想法和实用技巧，可帮助您增强编码能力并开发您的编码大脑，这些技巧至今仍然适用。但这个更新版本对本书做了两处改进。

<a id="d24e151"></a>
第一个是显而易见的：它删除了一些旧的参考文献、过时的示例，并用新鲜的、现代的内容替换它们。您不会找到循环不变量或构建机器的示例。戴夫和安迪采用了他们强大的内容，并确保课程仍然能够顺利完成，不受旧示例的干扰。它清除了像 DRY 这样的旧想法（不要重复自己），并给它们涂上一层新的油漆，真正让它们闪闪发光。

<a id="d24e153"></a>
但第二点才是这个版本真正令人兴奋的原因。写完第一版后，他们有机会反思自己想要表达的内容、希望读者从中学到什么以及读者如何接受这些内容。他们收到了有关这些课程的反馈。他们看到了什么是卡住的，什么是需要改进的，什么是被误解的。这本书在全世界程序员的手中和心中流传了二十年，戴夫和安迪研究了这种反应，并提出了新的想法、新的概念。

<a id="d24e155"></a>
他们已经了解了代理的重要性，并认识到开发人员可以说比大多数其他专业人士拥有更多的代理。他们以简单而深刻的信息开始这本书：“这是你的生活。”它提醒我们在代码库、工作和职业生涯中我们自己的力量。它为本书中的其他内容定下了基调——它不仅仅是另一本充满代码示例的技术书籍。

<a id="d24e157"></a>
它真正在众多技术书籍中脱颖而出的原因在于它理解成为一名程序员意味着什么。编程就是努力让未来不再那么痛苦。这是为了让我们的队友的事情变得更容易。这是关于犯错并能够恢复过来。这是关于养成良好的习惯。这是关于了解您的工具集。编码只是程序员世界的一部分，本书将探索这个世界。

<a id="d24e159"></a>
我花了很多时间思考编码之旅。我并不是在编码过程中长大的；我大学时没学过。我的青少年时期并没有花在摆弄科技上。我在二十多岁的时候进入了编码世界，必须了解成为一名程序员意味着什么。这个社区与我曾经加入过的其他社区非常不同。对学习和实践的独特奉献精神既令人耳目一新，又令人生畏。

<a id="d24e161"></a>
对我来说，真的感觉就像进入了一个新世界。至少是一个新城镇。我必须认识邻居，选择我的杂货店，找到最好的咖啡店。我们花了一段时间才了解情况，找到最有效的路线，避开交通最繁忙的街道，知道交通何时可能会发生。天气不同了，我需要一个新衣柜。

<a id="d24e164"></a>
在新城镇的最初几周甚至几个月可能会很可怕。有一个友好、知识渊博、已经在那里住了一段时间的邻居不是很棒吗？谁可以带你参观一下，带你看看那些咖啡店？一个在那里呆了足够长的时间、了解当地文化、了解小镇脉搏的人，让您不仅有宾至如归的感觉，而且还成为一名有贡献的成员？戴夫和安迪是邻居。

<a id="d24e166"></a>
作为一个相对较新的人，很容易被淹没的不是编程的行为，而是成为程序员的过程。需要发生彻底的思维转变——习惯、行为和期望的改变。成为一名更好的程序员的过程不仅仅因为你知道如何编码而发生；而是因为你知道如何编码。必须通过意图和刻意练习来实现这一点。本书是一本有效成为更好的程序员的指南。

<a id="d24e168"></a>
但请不要误会，它并没有告诉您编程应该如何进行。这不是哲学或判断的方式。它简单明了地告诉您什么是务实程序员——他们如何操作，以及他们如何处理代码。他们让你决定是否想成为其中一员。如果你觉得这不适合你，他们不会反对你。但如果您决定这样做，他们就是您的友好邻居，会为您指路。
