# 第 10 章 - 后记

> 从长远来看，我们塑造了我们的生活，也塑造了我们自己。这个过程永远不会结束，直到我们死为止。我们所做的选择最终是我们自己的责任。
>
> 埃莉诺·罗斯福

<a id="d24e27580"></a>
在第一版发布之前的二十年里，我们参与了计算机从外围好奇心到现代企业必需品的演变。此后的二十年里，软件已经超越了单纯的商业机器，真正占领了世界。但这对我们来说到底意味着什么？

<a id="d24e27607"></a>
在 神话人月：软件工程论文* [Bro96] 中，Fred Brooks 说：“程序员就像诗人一样，工作时只是稍微脱离了纯粹的思想。他在空中建造了自己的城堡，通过发挥想象力进行创造。”我们从一张空白页开始，几乎可以创建任何我们能想象到的东西。我们创造的东西可以改变世界。

<a id="d24e27617"></a>
从帮助人们计划革命的 Twitter，到汽车中防止打滑的处理器，再到智能手机（这意味着我们不再需要记住烦人的日常细节），我们的程序无处不在。我们的想象力无处不在。

<a id="d24e27619"></a>
我们开发人员非常荣幸。我们正在真正建设未来。这是一种非凡的力量。伴随着这种力量而来的是非凡的责任。

<a id="d24e27621"></a>
我们多久停下来思考一下这个问题？我们自己和更广泛的受众多久讨论一次这意味着什么？

<a id="d24e27624"></a>
嵌入式设备使用的计算机比笔记本电脑、台式机和数据中心使用的计算机多一个数量级。这些嵌入式计算机通常控制生命攸关的系统，从发电厂到汽车再到医疗设备。即使是一个简单的中央供暖控制系统或家用电器，如果设计或实施不当，也可能会致命。当您为这些设备进行开发时，您将承担巨大的责任。

<a id="d24e27626"></a>
许多非嵌入式系统也可能带来巨大的好处和巨大的危害。社交媒体可以促进和平革命或煽动丑陋的仇恨。大数据可以让购物变得更容易，它可以摧毁你可能认为自己拥有的任何隐私痕迹。银行系统做出的贷款决策可以改变人们的生活。几乎任何系统都可以用来窥探其用户。

<a id="d24e27630"></a>
我们已经看到了乌托邦未来的可能性的暗示，以及导致噩梦般的反乌托邦的意外后果的例子。两种结果之间的差异可能比您想象的更微妙。这一切都在你的手中。
